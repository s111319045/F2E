# Synk.paper 居家共居電子紙看板 - 官方網站展示專案

本專案為 **Synk.paper** 畢業設計展示 Landing Page，採用模組化標準前端架構（HTML5 / CSS3 / Vanilla JavaScript）。

---

## 專案目錄結構

```text
SynkPaper/
├── index.html       # 網頁骨架與所有頁面區塊結構（包含 Hero、簡報、互動模擬器、便條牆、技術規格、專案團隊）
├── style.css        # 自訂樣式庫（電子墨水刷新動畫、E-ink 微粒子游標、方格點陣底紋、捲動槽鎖定等）
├── main.js          # 核心互動程式（狀態引擎、即時房門看板切換、便條牆即時張貼/撕除、簡報輪播、問卷系統）
└── README.md        # 專案說明文件
```

---

## 如何開啟與執行

### 方法一：直接點擊開啟（零伺服器依賴）
- 在 Windows 檔案總管中，直接對 `index.html` 按兩下，即可在 Chrome、Edge、Firefox 等任何現代瀏覽器開啟並完整體驗所有功能。

### 方法二：本機伺服器運行（推薦用於開發或遠端分享）
若您使用 VS Code、Node.js 或 Python，可在專案目錄下啟動本機伺服器：
```bash
# 使用 Python 快速啟動本機伺服器
python -m http.server 3000
```
開啟瀏覽器前往 `http://localhost:3000` 即可預覽。

## 主要功能特色
1. **電子紙看板互動模擬器**：支援即時切換線上會議、專注模式、訪客預告等真實 E-ink 狀態與局部刷新黑白微粒粒子反轉效果。
2. **共居微紙便條牆**：即時發布便條、選擇三色紙張氛圍，並支援在看板上撕除標記完成。
3. **特製電子墨水游標（Custom E-ink Cursor）**：滑鼠懸停至按鈕、卡片與電子紙螢幕時，游標會變形為黑白墨水圈並伴隨墨滴擴散波紋。
4. **全頁智慧滾輪吸附（Snap Scroll）**：自動依照區塊精準吸附換頁，並具備右側章節導覽點即時同步。
5. **安全狀態自我修復引擎**：即便瀏覽器快取異常，狀態引擎皆具備完整 Fallback 防護，確保文字、題目、簡報標題永不缺漏。
